# Kwork Helper 2.0 🚀

**Kwork Helper** — это мощный Userscript для оптимизации работы на бирже фриланса [Kwork.ru](https://kwork.ru/projects). Скрипт добавляет полезную статистику, фильтрует спам, включает бесконечную прокрутку и интегрирует искусственный интеллект для быстрого анализа заказов.

![Version](https://img.shields.io/badge/version-2.0.0-black) ![Kwork](https://img.shields.io/badge/platform-Kwork-green)

## ✨ Основные возможности

### 🤖 AI Интеграция
- Добавляет кнопку **🤖** рядом с заголовком каждого заказа.
- **Анализ заказа:** Нейросеть (GPT-4o-mini или другая) анализирует описание, бюджет и заголовок.
- **Помощь в решении:** Подсказывает, адекватна ли цена, есть ли подводные камни и стоит ли откликаться.
- *Настраиваемый промпт и поддержка OpenRouter/OpenAI API.*

### 🛡️ Умный спам-фильтр и стоп-слова
- Автоматически помечает серым цветом (или скрывает) заказы, содержащие стоп-слова.
- **Встроенная база:** "за отзыв", "бесплатно", "за процент", "бюджет 0" и т.д.
- **Свои фильтры:** Вы можете добавлять собственные стоп-слова через настройки.

### 📊 Визуальная статистика и подсветка
- **Цветовые маркеры цен:**
  - 🟢 Зеленая полоса: Хороший бюджет (> 3000₽).
  - 🔴 Красная полоса: Низкий бюджет (< 500₽).
- **Надежность заказчика:**
  - Заменяет текст "Нанято: X%" на понятные бейджи:
  - 🛡️ **Надежный** (Нанято > 40%)
  - ⚠️ **Риск** (Нанято < 20%)
- **Срочность:** Добавляет огонек 🔥 для заказов со словами "срочно", "сегодня", "горит".

### ♾️ Бесконечная лента (Infinite Scroll)
- Забудьте про переключение страниц. Новые заказы подгружаются автоматически, когда вы доскроллили вниз.

### 🔄 Авто-обновление
- Таймер обновления страницы (по умолчанию 60 сек), чтобы ловить заказы первым.
- Визуальная пульсация кнопки, когда таймер активен.

## 📥 Установка

1. Установите расширение **Tampermonkey** для вашего браузера:
   - [Chrome / Edge](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   - [Firefox](https://addons.mozilla.org/ru/firefox/addon/tampermonkey/)
   - [Opera](https://addons.opera.com/ru/extensions/details/tampermonkey-beta/)
2. Нажмите на ссылку установки скрипта (или создайте новый скрипт в Tampermonkey и скопируйте код).
   - [**Установить Kwork Helper**](https://raw.githubusercontent.com/hermanguilliman/kwork-helper/main/kwork-helper.user.js) *(Убедитесь, что ссылка ведет на raw-файл)*.
3. Перейдите на [Биржу Kwork](https://kwork.ru/projects).

## ⚙️ Настройка

Слева на экране появится плавающая кнопка **"KH"**.

### Панель быстрого доступа
Наведите на кнопку, чтобы открыть меню:
- **Авто-обновление:** Вкл/Выкл таймер перезагрузки.
- **Скрывать спам:** Если включено, спам-заказы полностью исчезают. Если выключено — они просто становятся полупрозрачными.
- **Бесконечная лента:** Вкл/Выкл подгрузку страниц.

### 🛠 Глобальные настройки (AI и Стоп-слова)
Нажмите на иконку шестеренки **⚙️** в панели меню.

1. **Фильтр стоп-слов:**
   - Введите слово и нажмите `+` или Enter.
   - Нажмите на крестик, чтобы удалить слово из фильтра.
2. **Настройки нейросети:**
   - **Base URL:** Адрес API. По умолчанию `https://api.openai.com/v1`. Можно использовать `https://openrouter.ai/api/v1` для доступа к разным моделям из РФ без VPN (при наличии ключа OpenRouter).
   - **API Key:** Ваш ключ от OpenAI или OpenRouter. *Ключ хранится только в вашем браузере (localStorage).*
   - **Model:** Имя модели (например, `gpt-4o-mini`, `gpt-3.5-turbo`, `liquid/lfm-40b` и т.д.).
   - **System Prompt:** Инструкция для нейросети (как она должна анализировать заказ).

## ❓ FAQ

**Q: Скрипт безопасен?**
A: Да. Скрипт работает полностью на стороне клиента. Ваш API ключ отправляется только на указанный вами сервер (OpenAI/OpenRouter) и никуда больше.

**Q: Почему не работает AI?**
A: Проверьте консоль браузера (F12) на наличие ошибок.
1. Убедитесь, что указан правильный API Key.
2. Если вы в РФ и используете OpenAI, нужен VPN.
3. Рекомендуется использовать **OpenRouter**, так как он работает стабильнее и предоставляет доступ к дешевым моделям.

**Q: Как обновить скрипт?**
A: Если скрипт установлен через Tampermonkey по ссылке, он будет обновляться автоматически (или через проверку обновлений в расширении).
