# 🚀 Kwork Helper

![Version](https://img.shields.io/badge/version-1.0-blue) ![Author](https://img.shields.io/badge/author-Herman%20Guilliman-green) ![Platform](https://img.shields.io/badge/platform-Kwork.ru-orange)

**Kwork Helper** — это пользовательский скрипт для фриланс-биржи [Kwork.ru](https://kwork.ru). Он полностью преображает ленту заказов, помогая вам работать быстрее, видеть скрытые детали и избегать недобросовестных заказчиков.

> **Экономьте время, берите лучшие заказы и фильтруйте мусор автоматически.**

---

## ✨ Возможности

### 📊 Умная статистика заказчика
Больше не нужно вглядываться в мелкий текст. Скрипт заменяет строку "Нанято: X%" на яркие информативные плашки:
- 🛡️ **Надежный** (Зеленый): Процент найма > 40%.
- ⚖️ **Средний** (Желтый): Процент найма 20-40%.
- ⚠️ **Риск** (Красный): Процент найма < 20%.
- ❓ **Нет данных**: Если заказчик новичок.

### 🚫 Фильтр спама
Автоматически находит заказы со стоп-словами (*"за отзыв"*, *"бюджет потом"*, *"бесплатно"*). Такие заказы становятся полупрозрачными и помечаются тегом **SPAM**, чтобы не отвлекать ваше внимание.
> *Вы можете редактировать список стоп-слов в настройках.*

### 🔥 Детектор срочности
Если в заголовке или описании есть слова *"Срочно"*, *"ASAP"*, *"Горит"* — скрипт добавит иконку 🔥 прямо к заголовку, чтобы вы могли откликнуться первым.

### 📝 Заметки о пользователях
Кликните на иконку ✏️ рядом с именем заказчика, чтобы оставить о нем личную заметку (например, *"Платит щедро"* или *"Тяжелый клиент"*). Заметка сохранится и будет видна при всех будущих встречах с этим заказчиком.

### 📜 Бесконечная лента
Больше не нужно кликать по страницам пагинации! Скрипт автоматически подгружает новые заказы, когда вы прокручиваете ленту вниз.

### 🎨 Современный UI
- Удобная сворачиваемая панель управления с иконкой **KH**.
- Быстрое копирование заголовка заказа одной кнопкой `❐`.
- Цветовая индикация бюджета (зеленая полоса для дорогих заказов, красный фон для дешевых).

## ⚙️ Как пользоваться

После установки слева на экране появится круглая кнопка **KH**.

1. **Меню:** Нажмите на кнопку **KH**, чтобы открыть панель управления.
2. **Настройки:**
   - **Авто-обновление:** Включает таймер обновления страницы.
   - **Скрывать спам:** Если включено, спам-заказы будут полностью скрыты из ленты (иначе — просто станут прозрачными).
3. **Редактор слов:** Нажмите на шестеренку ⚙️ в меню, чтобы добавить или удалить стоп-слова для фильтра.
